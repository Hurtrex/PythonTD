Structure d’un projet Python
Le module
• Module: un fichier de code Python
• Un module peut contient plusieurs classes
  ou simplement des fonctions.
• Pour utiliser les définitions déjà faites, il
  faut utiliser le mot-clé import.
Structure d’un projet Python:
Importer un module
• Python lui-même est bâti sur des centaines de
  modules qui réalisent diverses tâches (math,
  re, os, time, urllib, etc.) qui sont préinstallés.
• Pour utiliser un module, il faut l’importer.
• On peut importer un élément spécifique d’un
  module ou tous les éléments d’un module.
• Il est possible de définir un alias pour un
  module afin de raccourcir son nom ou lui
  donner un nouveau nom significatif dans son
  propre code.
• Pour vider de la mémoire d’un module déjà
  chargé, on peut utiliser l’instruction del.
Structure d’un projet Python:
Ajouter un fichier __init_.py
• Un Package Python est un répertoire qui
  contient un ensemble de modules Python.
  Rappelez-vous, un module est tout
  simplement un fichier d’instructions Python.
• Ajouter un fichier __init__.py dans un
  répertoire Python permet d’importer tous les
  modules indiqués dans ce fichier ce qui
  réduit le nombre d’imports que l’on pourrait
  mettre au début d’un module.

La classe
• From/import pour inclure
  d’autres définitions de
  classes ou de code.
• Mot clé self est équivalent à
  Java this
• Héritage est indiqué avec le
  nom de la classe et peut être
  multiple.
• Fonction __int__ est le
  constructeur. On peut
  surcharger le constructeur.
• Les variable précédés par
  self dans __init__ sont des
  variable d’instance.
• Les variables hors __init__
  sont des variables de classe.
La classe:
Les modificateurs d’accès
• Comme tout langage de POO, Python
  possède les trois modes d’accès public,
  protected (_) et private (__). Les noms
  des membres privés et protégés
  commencent par _/__ mais ne se
  terminent pas avec ces symboles (à
  l’instar des dunder methods)
Méthode de l’instance
• Mot-clé self est présent parmi les
  paramètres.
• Symbol -> pour retourner un
  résultat.
• Les paramètres peuvent être typés
  (typage statique) ou non typés
  (typage dynamique)
• Accès aux variables d’instance
  avec le mot-clé self.
• La variable qui n’est pas précédée
  par self est locale.
• Une fonction peut retourner plus
  d’un résultat (un tuple)
• Les paramètres peuvent avoir une
  valeur par défaut.
• On peut affecter dynamiquement
  une méthode à une classe.
Méthode de classe (statique)
• Deux façons pour associer une méthode
  statique à une classe :
     • L’annotation @classmethod : la méthode de
       classe (statique) doit être annotée avec le
       décorateur @classmethod et avoir comme
       premier paramètre cls.
     • De façon dynamique en affectant une fonction à
       une classe avec l’instruction
       classmethod(theMethod)

Dunder methds:
__del__ et __delete__
• __del__ est le destructeur. Cette méthode
  est appelé avec l’instruction del ou
  automatiquement par le GC quand le
  nombre de références à l’objet est nul.
• _delete__ permet d’effacer une variable
  d’une classe
Dunder methods:
Comparaison des objets
• __cmp__ n’est plus présente dans
  Python 3
• Avec le décorateurde classe

   Les collections Python :
   la liste
   • Python autorise la construction de liste
     contenant des valeurs de types différents.
   • Les indices d'une liste de n éléments
     commence à 0 et se termine à n-1.
   • La liste peut également être indexée avec
     des nombres négatifs
   • On peut sélectionner une partie d'une
     liste en utilisant un indiçage construit sur
     le modèle [m:n+1] pour récupérer tous les
     éléments, du émième au énième (de
     l'élément m inclus à l'élément n+1 exclu).
   • On peut aussi préciser le pas en ajoutant
     un symbole deux-points supplémentaire
     et en indiquant le pas par un entier.
   • Plusieurs méthodes applicables: len, min,
     max, sum, append, etc.

le tuple
• Les tuples (« n-uplets » en français) correspondent aux listes à la
  différence qu’ils sont non modifiables. Ils utilisent les parenthèses au
  lieu des crochets.
• On peut construire un tuple à partir d’une liste avec tuple([e1, e2, …])
• On peut construire un tuple directement avec (e1, e2, …)
Les itérateurs :

• Un itérateur est un objet qui contient un
  nombre dénombrable de valeurs. Il peut
  être itéré, ce qui signifie que vous pouvez
  parcourir toutes les valeurs.
• En Python, un itérateur est un objet qui
  implémente le protocole d'itérateur
  composé des trois méthodes __init(),
  __next __ () et __iter __ ().
• On peut appliquer ce protocole à
  n’importe quel conteneur ayant des
  valeurs/objets.
Les exceptions
• Si une exception se produit, mais que la clause except dans le code ne la
  gère pas, elle est transmise aux instructions try externes. Si l'exception
  n'est pas gérée, l'exécution s'arrête.
• L'instruction raise permet de forcer une exception spécifique à se produire.

Notions Python supplémentaires:
Tests des valeurs sur des floats
• Les valeurs de float ne peuvent
  être qu’approchées. Une manière
  de s’en rendre compte est
  d’utiliser l’écriture formatée en
  demandant l’affichage d’un
  nombre variable de décimales.
• Il ne faut surtout pas tester si un
  float est égal à une certaine
  valeur.
• La bonne pratique est de vérifier
  si un float est compris dans un
  intervalle avec une certaine
  précision. Si on appelle cette
  précision delta, on peut procéder
  comme illustrer ci-contre
Notions Python supplémentaires:
manipuler une chaine de caractères
• Considérée comme une liste non modifiable de caractères (Java String)
• Peut être manipuler avec l’opérateur []
   • [3] est le 3ème caractère dans la chaine.
   • [-3:] les trois derniers caractères
   • [0:4] les 4 premiers caractères
   • [9:] les caractères à partir de la 9ème position jusqu’à la fin
   • [:-2] tous les caractères de la chaine sauf les deux derniers caractères
   • [0:] = [:len(name)] la chaine entière
• Les fonctions int(), float(), str() permettent de passer d’un nombre vers
  une chaine de caractères et vice versa.
